# Compass MVP scope / Alcance del MVP de Compass

## Español

El piloto de SMID Compass ofrecerá orientación sobre pasaportes venezolanos y talleres de SMID en español y alemán. El acceso inicial será mediante el Linktree de SMID. Los casos de uso son solicitar orientación sobre pasaportes, consultar talleres, continuar una consulta y recibir una redirección si la consulta está fuera de alcance. La integración con la web institucional se trabajará en paralelo. El feedback del piloto informará su diseño.

## English

The SMID Compass pilot will offer guidance on Venezuelan passports and SMID workshops in Spanish and German. Initial access will be through SMID's Linktree. Use cases include asking for passport guidance, finding workshops, following up on a previous question, and receiving a redirect when a request is outside the supported scope. Work on the organization website integration will proceed in parallel. Pilot feedback will inform its design.

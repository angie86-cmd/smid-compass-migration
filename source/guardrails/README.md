# Source Guardrails

This directory holds the exported Microsoft Foundry guardrail configuration from the private Azure tenant (SMID-Guardrails-Policy).

The guardrail configuration should be documented here as source configuration — an unedited record of what the policy looks like in the private tenant — rather than being treated as something to reuse directly. When the guardrail is recreated in the nonprofit tenant, it must be rebuilt as a new policy with new resource IDs; source resource IDs from this snapshot must not be reused in the target tenant.
